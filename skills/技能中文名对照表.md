# 技能中文名对照表

> 63 个技能，文件夹名保持英文（英文名是 AI 工具的加载标识，改了会加载失败）。
> 这张表的作用是：**让你能一眼看出每个文件夹是干什么的**，不用点进去读英文。

**怎么用：** 想知道某个技能能干什么 → 在下面搜中文名 → 照着左边的文件夹名去 `skills/` 里找。

## 为什么文件夹名不改成中文

看起来中文化更亲切，但有三个硬约束：

1. **目录名就是加载标识。** 五家 AI 工具（WorkBuddy / Cursor / Claude Code / VS Code / BYOK）
   都靠扫描 `<技能库>\<目录名>\SKILL.md` 认技能，目录名和 frontmatter 里的 `name:` 必须一致。
2. **符号链接跨三家共用。** 一个真实目录 + 三个链接指向它，避免版本分叉。
   改名要同时改链接目标、安装脚本、`docs/skills-manifest.json`、各agents 规则文件。
3. **非 ASCII 目录名兼容性未验证。** 部分工具的插件清单和路径匹配对中文目录名不一定稳。

**所以约定：目录名保持英文 + 这张中文对照表。** 两者都想要，就靠这张表。

# 资质闸门与合规

> **数据截止 2026-09。** 平台字数限制、保证金、类目名、抽成比例均为参考值，会随时变；交付与上架前一律**以后台当前实际要求为准**。

生成任何上架物料前先跑这一份。闸门不过就换路径，不要硬做。

## 一、三道硬闸门

开店不是「注册个账号」这么简单，三道门槛按顺序卡人，任何一道不过，后面全部作废。

### 闸门 1 —— 年龄

| 平台 | 要求 |
|---|---|
| 淘宝 | 开店需实名认证，要求年满 18 周岁。16–18 周岁需监护人代为签署并承担连带责任；实践中个人 C 店基本要求成年 |
| 拼多多 | 个人店需实名认证，同样要求成年；企业店需营业执照 |

**年龄不满足平台要求时的实际可行路径**：由监护人（父母）实名开店，本人做技术提供方。这是唯一合规做法。不要用他人身份证信息注册——那是违法行为，不是「变通」。

### 闸门 2 —— 实名与联系方式

开店需身份证 + 手机号 + 银行卡或支付宝。缺手机号这条路直接断，先去办号，没有替代方案。

### 闸门 3 —— 收款

货款必须走平台绑定的实名账户（支付宝 / 微信支付 / 银行卡）。收款账户姓名需与实名认证一致。

**闸门判定输出格式**（写进 `00-交付说明.md`）：

```
闸门 1 年龄    ：❌ 未满 18 周岁
闸门 2 实名    ：❌ 无手机号 / 无身份证
闸门 3 收款    ：❌ 无实名收款账户
结论：不具备开店条件 → 不生成上架物料，改走替代发行路径
```

任一为 ❌ 时，`gen_listing.py` 应在 `00-交付说明.md` 顶部打印醒目结论，且不输出标题/详情页等上架文案（避免用户拿着必然失败的物料去试错）。

## 二、平台规则风险

| 风险 | 后果 |
|---|---|
| 第三方工具自动化操作卖家后台 | 违反平台规则，封店 + 扣保证金。**不要做** |
| 代他人发布商品（无店铺授权） | 同上 |
| 虚拟商品类目未缴保证金 | 商品被下架或无法发布 |
| 盗用图片 / 详情页 | 侵权投诉，店铺扣分 |

## 三、AI 产品合规（应用含 AI 功能时）

**结论：自带 Key（BYOK）是唯一干净的路。**

- 自己搭服务器转发 AI 请求 = 成为「生成式 AI 服务提供者」，需算法备案 + 内容安全审核。个人办不了，年龄不满足平台要求时更办不了。淘宝还会查类目资质。
- 正确做法：让买家填自己的 baseURL / model / key。产品定性退回「软件」，成本与责任全隔离。
- **不要做多账号轮换 key 薅额度**：违反上游 ToS，按支付方式 / 设备指纹 / IP 段一起封。

若 `has_ai_feature: true` 且 `ai_byok: false`，必须在交付说明里标注：**当前形态不具备上架条件，需改为 BYOK**。

## 四、IP 风险

上架前逐条核对：

1. 应用内是否出现第三方作品名、角色名、UI 布局的直接复制？→ 清掉，包括注释里的形容方式。
2. 素材（精灵图、音效、字体）是否全部自有或程序化生成？→ 有外部素材必须确认授权范围含商用。
3. 商品标题 / 搜索关键词是否在蹭他人作品名？→ 删掉。蹭词既是侵权，也会被平台判定为「傍名牌」。
4. 字体：详情页 HTML 与主图所用字体是否可商用？宋体/黑体正文一般安全，装饰性字库需确认。

第 1 条最容易漏。描述效果时写效果本身（「块状波浪带」「立体屋顶」），不要写「某某风格」。

## 五、替代发行路径（闸门不过时用）

按可执行性排序：

| 路径 | 门槛 | 说明 |
|---|---|---|
| 监护人实名开店 + 本人供货 | 需监护人配合 | **首选**。唯一能落到淘宝/拼多多的合规路径 |
| 爱发电 / 面包多 | 需实名 | 虚拟内容友好，抽成低，适合个人 |
| itch.io / Gumroad | 海外收款 | 需海外收款能力，游戏类友好 |
| Steam 独立发行 | 需 100 美元上架费 + 实名 | 游戏品质达标再考虑 |
| 免费发布 + 捐赠 | 无 | 沉淀作品集，为后续铺路 |

给建议时必须过一遍「年龄 + 手机号 + 收款」三道门槛，不要给做不到的方案。

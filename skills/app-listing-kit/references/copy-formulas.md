# 文案公式与定价

> **数据截止 2026-09。** 平台字数限制、保证金、类目名、抽成比例均为参考值，会随时变；交付与上架前一律**以后台当前实际要求为准**。

## 一、标题公式

两平台的标题都被算法当检索字段用，核心是**词根覆盖**，不是文采。

```
[核心品类词] + [平台/运行环境词] + [强差异化卖点] + [人群或场景词]
```

**词根优先级**（从左到右权重递减，把最值钱的词放前面）：

1. 核心品类：`游戏` / `软件` / `工具`
2. 环境：`PC` / `电脑版` / `Windows` / `单机` / `免安装`
3. 差异卖点：`像素风` / `零素材` / `离线` / `体积极小`
4. 人群场景：`独立游戏` / `怀旧` / `打发时间`

**示例（30 字内）**：

```
像素风生存游戏 PC电脑单机版 免安装 中文 独立游戏 离线可玩
```

**禁忌**：

- 不堆砌无关热词（「网红同款」「ins风」用于游戏会拉低转化并被判违规）
- 不写他人作品名（侵权 + 傍名牌）
- 不写虚构数据（「已售1000+」）
- 不用极限词（见下）

## 二、卖点结构（5 条）

每条一个维度，避免同义重复。推荐维度顺序：

1. **第一句必须是「是什么」** —— 一句话说清玩家买到的是什么，不要抒情
2. **差异化** —— 别人没有你有的那一点
3. **技术亮点** —— 体积极小 / 零依赖 / 兼容性好，这类可验证的事实最有说服力
4. **上手成本** —— 解压即玩 / 无需配置 / 无需联网
5. **售后保障** —— 永久可重新下载 / 问题随时联系

单条控制在 20–30 字。写「事实」不写「感受」。

## 三、详情页分屏结构

详情页是纵向长图，用户从上往下扫。推荐 6 屏：

| 屏 | 作用 | 内容 |
|---|---|---|
| 1 | 决定性信息 | 应用名 + 一句话定位 + 一张代表性画面 |
| 2 | 核心玩法/功能 | 3–4 个要点，图标 + 短句 |
| 3 | 差异化 | 「这和你见过的同类有什么不同」 |
| 4 | 技术实感 | 体积 / 依赖 / 兼容性等可核对的数据 |
| 5 | 交付与安装 | 三步走图示，降低决策门槛 |
| 6 | 售后与承诺 | 常见问题 3 条 + 联系方式 |

第 5、6 屏最容易被忽略，但对虚拟商品转化影响最大——买家最大的顾虑是「我买了怎么拿到、出问题找谁」。

## 四、主图文案（5 张）

| 张次 | 内容 | 构图要点 |
|---|---|---|
| 1 | 白底主图 | 纯色底 + 应用名 + 一句话卖点。平台有自动抠图要求，务必留白充足 |
| 2 | 游戏画面 | 真实运行截图，不要渲染图 |
| 3 | 玩法亮点 | 3 个短卖点竖排，字号足够大 |
| 4 | 配置要求 | 最低配置 / 推荐配置，用表格 |
| 5 | 交付说明 | 「拍下自动发货 · 网盘直链 · 永久可下」 |

主图字数越少越好。缩略图尺寸下超过 12 个字基本读不清。

## 五、定价

**虚拟商品定价逻辑**：

- 锚定同类独立游戏均价区间。国产小体量独立游戏线上主流区间为 6–30 元。
- **不要定 1 元或 0.1 元走量**。低价吸引的是退款率和差评率最高的人群，且低价店会被平台打上低质标签。
- 双 SKU 阶梯：标准版 + 豪华版。豪华版的作用是**锚定**，让标准版显得便宜。豪华版价差控制在本体的 1.5–2.5 倍。
- 首单不搞「限时 1 折」。虚拟商品没有库存压力，价格战只会伤毛利。

**SKU 命名**：直接写清楚包含什么，不要用「A套餐/B套餐」，买家会反复问。

```
最、最佳、最好、最优、最强、最低、最高、第一、首选、顶级、极致、绝无仅有、
独一无二、史无前例、前所未有、绝对、100%、全网、全网最低、国家级、世界级、
领导品牌、王牌、独家、万能、永久免费、包治、无效退款、点击领奖、免费领、
限时抢购（无依据）、仅此一次、错过不再
```

### 虚拟商品高危词

```
破解、破解版、绿色免安装（易被判盗版）、外挂、辅助、脚本挂机、代练、
永久（作为承诺词）、无限下载、百度云破解、资源站、盗版、白嫖、
账号交易、租号、卡密解析、注册机、激活码生成器
```

### IP 风险词

任何第三方作品名、角色名、品牌名、影视名。包括「XX同款」「XX风」「像XX一样」。

### 处理原则

- 命中即改，不要「换个说法绕过」—— 判罚看的是实际语义。
- 「永久可重新下载」可以，单写「永久」不行（无依据承诺）。
- 「免安装」可以（描述安装方式），「绿色免安装」不行（涉盗版语义）。

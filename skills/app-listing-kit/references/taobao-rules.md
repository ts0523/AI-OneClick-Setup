# 淘宝上架参考

> **数据截止 2026-09。** 平台字数限制、保证金、类目名、抽成比例均为参考值，会随时变；交付与上架前一律**以后台当前实际要求为准**。

> 平台规则会变。以下为编写时的常见要求，**交付时必须标注「以后台当前实际要求为准」**。

## 一、标题

- 上限 **30 个汉字**（60 字符）。移动端展示会被截断，**前 15 字放最重要的词**。
- 词序权重：靠前的词根检索权重更高，把核心品类词放最前。
- 不要用特殊符号分隔（★、☆、【】堆砌会降权），用空格分词即可。

## 二、图片规格

| 类型 | 尺寸 | 要求 |
|---|---|---|
| 主图 | 800×800 起，推荐 800×800 或 750×1000 | 5 张。第 1 张必须白底、留白充足 |
| 详情页 | 宽 750px，高度不限 | 单张不超过 500KB，过长需切成多屏上传 |
| 主图视频 | 9:16 或 1:1 | 非必需，但对转化有明显帮助 |

详情页导出建议：浏览器打开 `03-详情页.html` → 整页截图 → 宽度缩到 750px → 按每 1500px 高度切图。

## 三、类目（虚拟 / 软件）

虚拟商品在淘宝的类目归属变化频繁，常见落点：

- 自研软件 / 工具：`电脑软件` 下的行业软件或系统软件类目
- 游戏：`游戏` 相关类目，或走「虚拟服务」类目
- 实体化交付（U 盘 / 光盘）可走实物类目，但成本与物流不划算

**类目选择直接决定保证金金额与资质要求**。虚拟类目保证金通常显著高于实物类目，发布前先在后台的类目选择页确认「该类目需要的资质与保证金」，不要凭经验猜。

**注意**：账号交易、代练、游戏币等类目已基本对个人关闭或严格限制。自研作品属另一类，但类目选择仍需按后台实际可选范围走。

## 四、属性填写

属性栏是检索字段的一部分，**能填满就填满**。带 `*` 为必填。

- 授权方式：选「自研」或「自主知识产权」
- 版本类型：正式版
- 运行环境：写清 Windows 版本
- 语种：简体中文

## 五、虚拟商品发货设置

淘宝虚拟商品推荐走**自动发货**：

1. 商品发布时选择「虚拟商品 / 自动发货」
2. 上传卡密库（每行一条），或设置网盘链接 + 提取码模板
3. 买家付款后系统自动发送

**卡密型更安全**：网盘链接容易被举报失效，卡密可追踪。但自研软件若走网盘交付，需准备**多个备用链接**并写进自动回复。

**发货时限**：实物类目 72 小时内，虚拟类目通常要求即时或 24 小时内。超时影响店铺体验分。

## 六、发布前 checklist（人工逐条点）

- [ ] 商品标题已按 30 字校验，前 15 字含核心词
- [ ] 主图 5 张齐全，第 1 张白底
- [ ] 详情页图片总大小已压缩，加载不卡
- [ ] 类目已选，且确认了该类目的资质与保证金要求
- [ ] 属性栏必填项全部填完
- [ ] 自动发货内容已测试（自己下一单验证发出来的内容能正常使用）
- [ ] 商品标题与详情页已跑过违禁词扫描
- [ ] 售后联系方式（旺旺 / 微信）已写入详情页
- [ ] 退款规则已明确（虚拟商品建议写「一经发货不支持退款」并说明理由）
